# Shell Scripting Masterclass

Welcome to the **Shell Scripting Masterclass** repository. This project is a curated, structured collection of shell scripts designed while   learning to  complete Linux beginner to an advanced power user. 

Each folder focuses on a core concept of the Linux operating system, automation, and DevOps fundamentals.

##  Repository Structure

The project is organized into the following modules:

* **`basics`**: Fundamental commands, file management, and navigating the Linux CLI.
* **`init_files_variables_and_expansions`**: Customizing environments, alias creation, local/global variables, and expansion techniques.
* **`io_redirections_and_filters`**: Mastering standard inputs/outputs, streams (`stdin`, `stdout`, `stderr`), pipes, and text manipulation tools.
* **`loops_conditions_and_parsing`**: Logic building with `if/else` statements, `while/for` loops, and parsing complex text or command outputs.
* **`permissions`**: Managing user roles, groups, read/write/execute (`chmod`, `chown`) rights, and security basics.
* **`processes_and_signals`**: Monitoring system performance, managing background jobs, and signaling processes (`kill`, `pkill`).

## 🚀 Getting Started

### Prerequisites
Used a Unix-like environment to run these scripts:
* Linux (Ubuntu, Debian, CentOS, etc.)
* macOS terminal
* Windows Subsystem for Linux (WSL)

### Installation

```bash

cd 23Ihirwe
```

##  How to Use and Run the Scripts

1. Navigate to the desired topic folder:
   ```bash
   cd permissions
   ```
2. Made sure the script has executable permissions:
   ```bash
   chmod +x script_name.sh
   ```
3. Executed the script:
   ```bash
   ./script_name.sh
   ```

---

##  Best Practices Followed
* **Shebang Line**: Every script starts with `#!/bin/bash` or `#!/usr/bin/env bash`.
* **Clean Code**: Well-commented logic to explain *why* a command is used.
* **Safety First**: Proper quoting to handle spaces and special characters securely.
